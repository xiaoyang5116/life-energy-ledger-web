# MVP 范围与流程

## 1. MVP 验证目标

MVP 只验证五件事：

1. 用户是否愿意用“生命能量”理解现金流。
2. 极速录入是否足够低摩擦，能否支撑持续记录。
3. 不在录入阶段选择支出 / 收入，是否能降低阻力。
4. 周末复盘是否能帮助用户看清生命流向。
5. 自动复盘是否能降低长期使用负担。

## 2. MVP 不做

- 复式记账
- 多账户资产管理
- 银行卡自动同步
- 发票识别
- 多币种支持
- 家庭账本
- 专业投资收益分析
- AI 自动分类
- 复杂财务报表
- 复杂预算系统
- 精确投资净值追踪
- 投资批次盈亏核算
- 账户间转账对账

## 3. 成功标准

| 指标             | 目标                                   |
| ---------------- | -------------------------------------- |
| 单笔记录完成时间 | 小于 3 秒                              |
| 快速录入字段数量 | 不超过 3 个：日期、金额、描述          |
| 连续记录天数     | 大于 7 天                              |
| 每周复盘完成率   | 大于 60%                               |
| 自动复盘命中率   | 第二周后大于 40%                       |
| 用户主观反馈     | 愿意继续记录，并觉得更理解自己的现金流 |

## 4. 信息架构

MVP 保留 3 个底部 Tab（首页、待复盘、设置），极速录入以底部抽屉叠加在 Tab 布局上，不单独占一级路由。

### 首页

作为自由仪表盘，展示当前生命能量状态。

核心内容：

- 本月已消耗生命能量
- 今日已消耗生命能量
- 本月值得的生命消耗
- 本月后悔的生命消耗
- 本月自由积累小时数
- 本月收入补充
- 待复盘分组数量
- 快速录入入口（打开录入抽屉）

### 极速录入（抽屉）

负责最低成本记录事实。从任意 Tab 的浮动入口打开底部抽屉，不做成常驻 Tab，也不使用全屏 `/record` 路由。

抽屉结构：

```text
[日期：今天]
[金额大数字]
[生命能量预览]
[描述输入框 + 快捷标签]
[数字键盘 + 再记 + 确认]
```

规则：

- 不提供必选的支出 / 收入切换。
- 金额统一按正数存储。
- 系统自动计算生命能量。
- 系统尝试匹配自动复盘规则。
- MVP 不含幽灵账、相机 / 拍照识别；后续产品再加。

### 待复盘页

负责承载需要用户复盘判断的现金流记录。

默认按 `descriptionKey` 分组，而不是逐笔展示。

每组展示：

- 笔数
- 总金额
- 总生命能量
- 系统建议
- 确认全部
- 重新判断

### 设置页

维护系统基础参数。

核心内容：

- 税后月工资
- 月通勤成本
- 每日工作小时
- 每月工作天数
- 每日通勤小时
- 真实时薪
- 生命流向管理
- 自动复盘规则管理
- 数据导出

## 5. 核心流程

### 初始化

用户首次进入产品，配置真实时薪参数。

系统计算：

```text
月工作时间 = 每日工作小时 × 每月工作天数
月通勤时间 = 每日通勤小时 × 每月工作天数
真实时薪 = (税后月工资 - 月通勤成本) / (月工作时间 + 月通勤时间)
```

### 极速录入

1. 用户输入日期、描述、金额。
2. 系统计算 `energyHours`。
3. 系统生成 `descriptionKey`。
4. 系统匹配 `AutoReviewRule`。
5. 未命中规则时，记录进入 `unreviewed`。
6. 命中规则且金额正常时，记录进入 `auto_reviewed`。
7. 命中规则但金额异常时，记录进入 `suggested`。

### 第一次复盘

1. 用户进入待复盘页。
2. 系统按描述分组展示未复盘记录。
3. 用户选择生命流向分类。
4. 系统从生命流向带出 `direction` 和 `statEffect`。
5. 若 `statEffect = consume`，用户填写三项复盘判断。
6. 系统确认该组记录为 `reviewed`。
7. 系统创建或更新自动复盘规则。

### 自动复盘

相同 `descriptionKey` 再次出现时：

1. 系统命中历史规则。
2. 自动填充生命流向、`direction`、`statEffect` 和复盘判断。
3. 金额正常则直接标记为 `auto_reviewed`。
4. 金额异常则标记为 `suggested`，等待确认。

## 6. 优先级

### P0 必须实现

- 初始化真实时薪配置
- 极速录入金额、描述、日期
- 录入阶段不选择支出 / 收入
- 金额统一按正数存储
- 生命能量换算
- `descriptionKey` 生成
- 原始记录列表
- 默认生命流向分类
- 生命流向内置 `direction` 和 `statEffect`
- 待复盘页按 `descriptionKey` 分组
- 第一次复盘
- 自动生成 `AutoReviewRule`
- 相同描述自动复盘
- 基础首页概览
- 本月生命消耗统计
- 本月自由积累统计

### P1 建议实现

- 金额异常进入 `suggested`
- 自动复盘规则管理页
- 满足感统计
- 价值观一致性统计
- 工作依赖成本统计
- 收入补充统计
- 退款抵消统计
- 数据导出
- PWA 添加到主屏幕

### P2 后续实现

- 幽灵账（突发状况先挂起、暂不正式记入）
- 相机 / 拍照识别辅助录入
- 关键词匹配
- 模糊匹配
- AI 辅助复盘
- 趋势图
- 周报
- FIRE 交叉点图表
- 多设备同步
- 分享图生成
- 投资批次追踪
- 退款关联原始消费
